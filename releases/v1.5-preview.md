# Def Jam Android v1.5 Preview

- Restored the custom touch-control artwork.
- Added experimental rollback and updated memory handling.
- Updated Discord sign-in and enabled Android lobby connections to the FFNY Online relays.

This ARM64 preview is intended for Android-to-Android lockstep testing. Discord sign-in, room connections and rematches still need device testing. It installs alongside previous versions.

Android port maintained by contatg. Multiplayer work is based on FFNY Online by sweeax-exe and contributors. Thanks to Vlad Yanhursky and the recompilation and runtime contributors. [Full credits](../CREDITS.md)
